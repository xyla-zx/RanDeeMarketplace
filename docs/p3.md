## 6. แนวทางการออกแบบ (Design Direction)

### 6.1 ที่มาของภาษาภาพ

ระบบนี้ไม่ใช่ SaaS dashboard และไม่ใช่เว็บแฟชั่น มันคือ **ตลาด** — ที่ที่คนเอาของมาวางขาย
ติดป้ายราคา ตะโกนเรียกลูกค้า ต่อรอง แล้วห่อของส่ง

วัสดุที่เป็นแก่นของภาพ: **ถ้วยชามเคลือบและป้ายเคลือบตราไก่** ที่อยู่ในตลาดไทยทุกแห่ง
ผิวขาวเคลือบมัน ขอบลงสีน้ำเงินครามคมชัด ลวดลายแดงชาด ตัวอักษรหนาอ่านง่ายจากระยะไกล
ของพวกนี้ถูกออกแบบมาเพื่อ "อ่านออกในที่แสงจ้าและใช้งานหนัก" ซึ่งตรงกับสิ่งที่แอปนี้ต้องการพอดี

สิ่งที่หยิบมาใช้จริง:

| ของจริง | แปลงเป็น UI |
|---|---|
| ขอบเคลือบสีครามรอบจาน | เส้นขอบ 1px สีคราม รอบ element ที่ interactive ได้ |
| ป้ายราคาเขียนมือปักบนของ | ป้ายราคาทรงตั๋วมีรอยบาก (notch) ด้วย `clip-path` |
| ตัวหนังสือหนาบนป้ายร้าน | พาดหัวน้ำหนัก 600-700 ตัวใหญ่ tracking แน่น |
| กระเบื้องพื้นร้านเรียงเป็นตาราง | grid ที่เห็นเส้นแบ่งชัด ไม่ลอยเป็นการ์ดแยกใบ |
| กล่องพัสดุกระดาษน้ำตาล | สีของสถานะ "กำลังจัดส่ง" และหน้าติดตามพัสดุ |

### 6.2 หลักการ 6 ข้อของหน้าตาระบบนี้

1. **ราคาคือพระเอก** ราคาต้องเป็นสิ่งที่ตาเห็นเป็นอันดับสองรองจากรูป ใช้ป้ายทรงตั๋วเสมอ
2. **เส้นแทนเงา** ใช้ border เป็นตัวแบ่งพื้นที่หลัก เงาใช้เฉพาะของที่ "ลอย" จริง ๆ
   (dropdown, sheet, toast) เท่านั้น ไม่มีเงาใต้การ์ดในฟีด
3. **ความโค้งบอกลำดับชั้น** รูป 4px, การ์ด 10px, ปุ่ม 8px, ชิป 999px, sheet 18px
   ห้ามใช้ค่าเดียวกันทั้งหน้า
4. **สีแดงคือของหายาก** สีแดงใช้ได้กับ 3 อย่างเท่านั้น: ส่วนลด, ของใกล้หมด, ข้อผิดพลาด
   ถ้าหน้าไหนมีแดงเกิน 2 จุด แปลว่าออกแบบผิด
5. **จังหวะเดียวที่เคลื่อนไหวเอง** ทั้งแอปมี motion ที่ไม่ได้เกิดจากผู้ใช้เพียงจุดเดียว
   คือป้ายสถานะร้าน "เปิดอยู่" ที่มีจุดเต้นเบา ๆ นอกนั้นต้องเกิดจากการกระทำเท่านั้น
6. **มือถือคือขนาดจริง** ออกแบบที่ 390px ก่อน แล้วค่อยขยาย ไม่ใช่ย่อจาก desktop

### 6.3 Hero ของแต่ละหน้าหลัก

ห้ามใช้ hero แบบ "พาดหัวใหญ่ + ซับ + ปุ่มคู่ + ภาพประกอบ" ซึ่งเป็นค่า default
แต่ละหน้ามี hero เฉพาะของตัวเอง:

- **หน้าแรก** — ช่องค้นหาขนาดใหญ่ที่มีคำค้นยอดนิยมจริงวิ่งเป็นรายการใต้ช่อง
  พร้อมตัวเลขของที่ลงขายวันนี้แบบนับขึ้นครั้งเดียวตอนโหลด
- **หน้าร้าน** — ป้ายหน้าร้านทรงป้ายเคลือบ กว้างเต็มคอนเทนเนอร์ สูง 132px
  ข้างในมีชื่อร้านตัวใหญ่ ป้ายยืนยัน คะแนน เวลาตอบเฉลี่ย และสถานะเปิด/ปิดแบบสด
- **หน้าโพสต์** — รูปสินค้าเต็มความกว้างบนมือถือ โดยมีป้ายราคาทรงตั๋วคร่อมขอบล่างของรูป
- **หน้าฟีด** — ไม่มี hero เริ่มที่แถบหมวดเลื่อนแนวนอนแล้วเข้ากริดทันที
- **หลังบ้านผู้ขาย** — แถวตัวเลข 4 ช่องที่ "มีความหมายต่อวันนี้" (ออเดอร์ใหม่, ต้องส่ง,
  แชทยังไม่ตอบ, เงินรอโอน) แต่ละช่องกดเข้าไปทำงานต่อได้ทันที ไม่ใช่ตัวเลขประดับ

### 6.4 เสียงและน้ำเสียงของข้อความ

- ใช้ประโยคบอกเล่า กริยาตรง ไม่ใช้คำขายของ
- ปุ่มบอกสิ่งที่จะเกิดขึ้น: "เผยแพร่โพสต์" ไม่ใช่ "ยืนยัน"
- ชื่อการกระทำต้องเหมือนกันตลอดทาง ปุ่ม "เผยแพร่" → toast "เผยแพร่แล้ว"
- ข้อผิดพลาดบอกว่าเกิดอะไรและต้องทำอะไรต่อ ไม่ขอโทษ ไม่คลุมเครือ
  - ผิด: "เกิดข้อผิดพลาด ขออภัยในความไม่สะดวก"
  - ถูก: "อัปโหลดรูปไม่สำเร็จเพราะไฟล์ใหญ่เกิน 12 MB ลองลดขนาดรูปแล้วอัปโหลดใหม่"
- หน้าว่างคือคำเชิญให้ลงมือ ไม่ใช่การบอกว่าไม่มีอะไร
  - ผิด: "ไม่พบข้อมูล"
  - ถูก: "ยังไม่มีโพสต์ในร้าน เริ่มจากของชิ้นที่ขายง่ายที่สุด" + ปุ่ม "สร้างโพสต์แรก"
- ห้ามใช้เครื่องหมายอัศเจรีย์ในข้อความระบบ ยกเว้นหน้าแสดงความสำเร็จของการขายชิ้นแรก

### 7.1 สีหลัก 6 สี

| ชื่อ | ค่า | ใช้กับ |
|---|---|---|
| Ink (หมึกคราม) | `#0D1B2A` | ตัวอักษรหลัก พื้นหลังแถบบนในโหมดมืด |
| Cobalt (คราม) | `#1B44C8` | ปุ่มหลัก ลิงก์ focus ring ขอบของ interactive |

- Kraft (กระดาษพัสดุ) `#9A6B3F` — สถานะกำลังจัดส่ง
- Amber (เหลืองป้ายเตือน) `#B8710A` — รอดำเนินการ คำเตือน

### 7.3 ตัวอักษร

**สองตระกูลเท่านั้น**

| บทบาท | ตระกูล | น้ำหนักที่ใช้ | ลักษณะ |
|---|---|---|---|
| พาดหัว ชื่อร้าน ราคา ตัวเลขสถิติ | Anuphan | 500, 600, 700 | ทรงเรขาคณิต หัวตัด อ่านชัดตัวใหญ่ |
| เนื้อความ ฟอร์ม ป้าย ปุ่ม | IBM Plex Sans Thai | 400, 500, 600 | มีหัว อ่านยาวสบายตา |

**ห้ามใช้ monospace ใน UI** ตัวเลขทั้งหมดใช้ `font-variant-numeric: tabular-nums`
เพื่อให้เรียงตรงคอลัมน์โดยไม่ต้องเปลี่ยนตระกูลฟอนต์

**สเกลและการตั้งค่า**

กฎเพิ่มเติม:
- ภาษาไทยต้องมี `line-height` ไม่ต่ำกว่า 1.6 ในเนื้อความ เพราะมีสระบนล่าง
- ห้ามใช้ `text-transform: uppercase` กับข้อความใด ๆ ในระบบ
- ความยาวบรรทัดเนื้อความไม่เกิน 68 ตัวอักษร
- ห้ามใส่ `letter-spacing` บวกกับข้อความภาษาไทย (ทำให้สระลอย)
- โหลดฟอนต์ด้วย `next/font/google` พร้อม `display: 'swap'` และ preload เฉพาะน้ำหนักที่ใช้จริง

## 8. ชุดไอคอน SVG

### 8.1 กฎของไอคอน

- ขนาด viewBox `0 0 24 24` เสมอ
- `stroke="currentColor"` `stroke-width="1.75"` `fill="none"`
  `stroke-linecap="round"` `stroke-linejoin="round"`
- ห้ามใส่สีตายตัวใน path ให้รับสีจาก `currentColor`
- ขนาดที่อนุญาต: 16, 20, 24, 32 (px) เท่านั้น
- ไอคอนที่อยู่ลำพังโดยไม่มีข้อความต้องมี `aria-label` ถ้ามีข้อความกำกับให้ใส่ `aria-hidden="true"`
- **ห้ามใช้ emoji แทนไอคอนทุกกรณี** ทั้งใน UI, อีเมล, การแจ้งเตือน, seed data

### 8.2 คอมโพเนนต์ไอคอน

```tsx
// packages/ui/src/icon/icon.tsx
import { paths, type IconName } from './paths'

export type IconProps = {
  name: IconName
  size?: 16 | 20 | 24 | 32
  className?: string
  label?: string          // ถ้าไม่ส่ง = ไอคอนประดับ
}

export function Icon({ name, size = 24, className, label }: IconProps) {
  return (
    <svg
      width={size} height={size} viewBox="0 0 24 24"
      fill="none" stroke="currentColor" strokeWidth={1.75}
      strokeLinecap="round" strokeLinejoin="round"
      className={className}
      role={label ? 'img' : undefined}
      aria-label={label}
      aria-hidden={label ? undefined : true}
      focusable="false"
    >
      {paths[name]}
    </svg>
  )
}
```
