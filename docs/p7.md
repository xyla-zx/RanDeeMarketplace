## 12. สเปกรายหน้า

รูปแบบการเขียนของแต่ละหน้า: เส้นทาง → เป้าหมาย → ส่วนประกอบ → สถานะ → เกณฑ์ผ่าน

### 12.1 หน้าแรก `/`

**เป้าหมาย**: ให้คนที่มาครั้งแรกเข้าใจใน 5 วินาทีว่าซื้อ-ขายอะไรได้ และเริ่มค้นหาทันที

**ส่วนประกอบเรียงจากบน**

1. แถบบน (sticky) — โลโก้, ช่องค้นหา (บนมือถือเป็นปุ่มที่เปิด overlay), ปุ่มเปิดร้าน, บัญชี
2. ช่องค้นหาใหญ่พร้อมคำค้นยอดนิยม 6 คำเป็นชิปใต้ช่อง (ข้อมูลจริงจาก 24 ชม.)
   ด้านขวาของช่องมีตัวเลข "ของใหม่วันนี้ 1,248 ชิ้น" นับขึ้นครั้งเดียวใน 800ms
3. แถบหมวดหมู่ 12 หมวด ไอคอนเส้น + ชื่อ เลื่อนแนวนอนบนมือถือ กริด 6x2 บนเดสก์ท็อป
4. "ใกล้คุณ" — ถ้าอนุญาตตำแหน่ง แสดงของในรัศมี 20 กม. 8 ชิ้น
   ถ้าไม่อนุญาต แสดงปุ่มขออนุญาตพร้อมเหตุผลว่าจะได้อะไร ไม่ใช่ popup ทันทีที่เข้าหน้า
5. "เพิ่งลงขาย" — 12 ชิ้นล่าสุดที่ผ่านการตรวจ
6. "ร้านน่าเชื่อถือ" — 8 ร้านที่คะแนน ≥ 4.7 และขายแล้ว ≥ 50
7. แถบชวนเปิดร้าน — ไม่ใช่ hero ซ้ำ แต่เป็นแถบเดียวสูง 180px มีขั้นตอน 3 ข้อจริง
8. ส่วนท้าย — ลิงก์นโยบาย ช่วยเหลือ ติดต่อ เลือกภาษา

**สถานะ**: skeleton ของทุกส่วนตอนโหลด, ถ้า API ล้มเหลวให้แสดงส่วนที่โหลดได้และซ่อนส่วนที่พัง

**เกณฑ์ผ่าน**: LCP ≤ 2.0s บน 4G, ไม่มี CLS จากรูปหรือฟอนต์, ใช้ JS ≤ 120KB gzip

### 12.2 ฟีด `/feed` และหมวด `/c/[slug]`

- แถบตัวกรองติดด้านบนเมื่อเลื่อน: หมวดย่อย, ราคา, สภาพ, จังหวัด, การจัดส่ง, เรียงลำดับ
- บนมือถือตัวกรองเปิดเป็น bottom sheet เต็มจอ มีปุ่ม "ล้างทั้งหมด" และปุ่ม
  "ดูผลลัพธ์ 342 ชิ้น" ที่อัปเดตเลขสดขณะเลือก
- ตัวกรองทุกตัวสะท้อนใน URL เพื่อแชร์และกดย้อนกลับได้
- โหลดเพิ่มแบบ infinite scroll ด้วย IntersectionObserver พร้อมปุ่ม "โหลดเพิ่ม" สำรอง
  สำหรับคนใช้คีย์บอร์ด และประกาศจำนวนที่โหลดใหม่ผ่าน `aria-live="polite"`
- จำตำแหน่งการเลื่อนเมื่อกดเข้าโพสต์แล้วย้อนกลับ
- การเรียงลำดับ: เกี่ยวข้องที่สุด (ค่าเริ่มต้น), ใหม่สุด, ราคาต่ำ-สูง, ราคาสูง-ต่ำ, ใกล้ฉัน, ขายดี

### 12.3 หน้าค้นหา `/search`

- ช่องค้นหาโฟกัสอัตโนมัติเมื่อเข้าจากปุ่มค้นหา
- คำแนะนำขณะพิมพ์แบ่ง 3 กลุ่ม: คำค้น, หมวดหมู่, ร้าน (มีไอคอนต่างกัน)
- คีย์บอร์ด: ลูกศรขึ้นลงเลือก, Enter ยืนยัน, Esc ปิด (`role="combobox"` + `aria-activedescendant`)
- ถ้าไม่พบผล: แสดงคำที่อาจหมายถึง, ผลใกล้เคียงจากหมวดเดียวกัน, ปุ่มบันทึกการค้นหานี้
- ประวัติการค้นหา 8 รายการล่าสุดเก็บใน localStorage ลบทีละรายการได้

### 12.4 หน้าโพสต์ `/p/[slug]`

ผังตามหัวข้อ 7.4 เพิ่มเติม:

- แกลเลอรี: ปัดบนมือถือ, บนเดสก์ท็อปคลิกเปิด lightbox พร้อมซูม
- ราคาจะเปลี่ยนทันทีเมื่อเลือกตัวเลือกย่อยที่ราคาต่างกัน พร้อม transition สั้น
- ถ้าเหลือ ≤ 3 ชิ้น แสดง StockMeter สี rooster ว่า "เหลือ 2 ชิ้น"
- ถ้าสินค้าหมด: ปุ่มซื้อเปลี่ยนเป็น "แจ้งเตือนเมื่อมีของ" และการ์ดแนะนำของคล้ายกัน
- ส่วนร้าน: ป้ายยืนยัน, คะแนน, เวลาตอบเฉลี่ย, อัตราส่งตรงเวลา, ปุ่มดูร้าน/ติดตาม
- ส่วนจัดส่ง: คำนวณจากจังหวัดของผู้ใช้ถ้ารู้ ถ้าไม่รู้ให้เลือกจังหวัดในที่นั้นเลย
- ส่วนรีวิว: แสดง 3 รีวิวล่าสุด + กราฟแท่งสัดส่วนดาว + ตัวกรอง "เฉพาะที่มีรูป"
- ปุ่ม "รายงานโพสต์นี้" อยู่ล่างสุด ขนาดเล็ก ไม่เด่น แต่หาเจอ
- แถบล่างติดหน้าจอบนมือถือ: ทักแชท / ใส่ตะกร้า / ซื้อเลย

**เกณฑ์ผ่าน**: มี structured data `Product` + `Offer` + `AggregateRating` ครบ,
รูปปกมี `priority`, สลับตัวเลือกไม่ทำให้หน้ากระตุก

### 12.5 หน้าร้าน `/s/[slug]`

- ป้ายหน้าร้านตามหัวข้อ 7.6
- แท็บ: สินค้าทั้งหมด / หมวดในร้าน / รีวิว / เกี่ยวกับร้าน
- แถบเครื่องมือในร้าน: ค้นหาในร้าน, เรียงลำดับ, กรองเฉพาะลดราคา
- โพสต์ที่ปักหมุดขึ้นก่อนเสมอ สูงสุด 3 ชิ้น มีป้าย "แนะนำโดยร้าน"
- ถ้าร้านลาพัก: แถบสีเหลืองบนสุดบอกวันที่กลับมาเปิด และปิดปุ่มซื้อทั้งหมด
- ส่วน "เกี่ยวกับร้าน": เวลาทำการเป็นตาราง 7 วัน, ที่ตั้ง (แผนที่เฉพาะเมื่อร้านยอมเปิดเผย),
  นโยบายคืนสินค้าของร้าน, วันที่เปิดร้าน

### 12.6 ฟอร์มสร้างโพสต์ `/seller/compose`

หน้าที่สำคัญที่สุดของทั้งระบบ ทำเป็น 3 ขั้นบนมือถือ และคอลัมน์เดียวเลื่อนยาวบนเดสก์ท็อป

```
ขั้น 1 — รูปและชื่อ
  [ พื้นที่วางรูป / ปุ่มเปิดกล้อง / เลือกจากคลัง ]
  ชื่อโพสต์ ………………………………………
  หมวดหมู่  [ เลือกหมวด ▾ ]   ← แนะนำอัตโนมัติจากชื่อและรูป
  (ปุ่มล่าง: ถัดไป)

ขั้น 2 — ราคาและรายละเอียด
  ราคา ฿ ……………     สภาพ [ใหม่][มือสอง…]
  [ ] รับข้อเสนอราคา → ราคาต่ำสุดที่รับ ฿ ……
  จำนวน [ − 1 + ]
  ตัวเลือกย่อย  [ + เพิ่มสี/ไซซ์ ]
  รายละเอียด ………………………………………
  คุณสมบัติตามหมวด (แบรนด์ / ไซซ์ / วัสดุ …)
  (ปุ่มล่าง: ถัดไป)

ขั้น 3 — จัดส่งและเผยแพร่
  น้ำหนัก …… กรัม   ขนาดกล่อง …×…×… ซม.
  วิธีส่ง [ ] ไปรษณีย์ไทย ฿40  [ ] Flash ฿45  [ ] นัดรับ
  [ ] เก็บเงินปลายทาง
  เผยแพร่ [ ทันที | ตั้งเวลา ]
  (ปุ่มล่าง: เผยแพร่โพสต์)
```

ข้อกำหนดพฤติกรรม:

1. **บันทึกร่างอัตโนมัติทุก 5 วินาที** และทุกครั้งที่เปลี่ยนขั้น เก็บทั้ง IndexedDB และ server
2. ถ้าปิดแท็บแล้วเปิดใหม่ ต้องถามว่า "ทำต่อจากร่างเมื่อ 10 นาทีที่แล้วไหม"
3. แถบความคืบหน้าด้านบนบอกขั้นที่อยู่ กดย้อนได้ ห้ามกดข้ามไปข้างหน้าถ้าขั้นก่อนไม่ครบ
4. ตรวจความถูกต้องเมื่อออกจากช่อง (onBlur) ไม่ใช่ทุกตัวอักษร
5. ข้อผิดพลาดแสดงใต้ช่อง และเลื่อนไปช่องแรกที่ผิดเมื่อกดถัดไป
6. แนะนำหมวดหมู่อัตโนมัติจากชื่อโพสต์ ด้วยการเทียบคำกับชื่อหมวดและ tag ยอดนิยม
7. ตัวช่วยคุณภาพโพสต์ (แถบข้าง): ให้คะแนน 0-100 จาก จำนวนรูป ความยาวคำอธิบาย
   ครบคุณสมบัติ มีตัวเลือกย่อย ราคาสมเหตุสมผลเทียบของคล้ายกัน
   แสดงเป็นรายการสิ่งที่ยังทำได้ ไม่ใช่แค่ตัวเลข
8. ปุ่มดูตัวอย่างเปิด sheet แสดงการ์ดเหมือนที่จะเห็นในฟีดจริง
9. หลังเผยแพร่: หน้าแสดงผลสำเร็จพร้อมลิงก์ ปุ่มแชร์ (คัดลอกลิงก์/LINE/Facebook)
   และปุ่ม "ลงอีกชิ้น" ที่คงค่าหมวด/จัดส่งไว้

### 12.7 เช็คเอาต์ `/checkout`

ขั้นเดียวเลื่อนยาว ไม่แบ่งหลายหน้า

```
1. ที่อยู่จัดส่ง        [ เลือก/เพิ่มที่อยู่ ]
2. รายการต่อร้าน       แยกกล่องตามร้าน แต่ละกล่องมี:
                       รายการสินค้า, วิธีส่งของร้านนั้น, ช่องข้อความถึงร้าน
3. คูปอง               ใส่โค้ด/เลือกจากที่มี
4. วิธีชำระเงิน          พร้อมเพย์ / บัตร / เก็บเงินปลายทาง (ถ้าทุกร้านรองรับ)
5. สรุปยอด             ยอดสินค้า, ค่าส่ง, ส่วนลด, ยอดชำระ (ตัวใหญ่)
   [ ชำระเงิน ฿1,540 ]  ← ปุ่มบอกยอดจริงเสมอ
```

- ตรวจสต็อกอีกครั้งตอนกดชำระ ถ้าไม่พอให้บอกรายชิ้นและให้แก้ในหน้าเดิม
- ล็อกสต็อก 15 นาทีเมื่อสร้างออเดอร์ (reservation) หมดเวลาแล้วคืน
- หน้า QR พร้อมเพย์: แสดง QR + ยอด + นับถอยหลัง + ปุ่มบันทึกรูป
  + ตรวจสถานะอัตโนมัติทุก 3 วินาที และผ่าน realtime
- จ่ายสำเร็จ: ไปหน้า `/orders/[code]` พร้อมแถบสำเร็จ ไม่ใช่ toast อย่างเดียว

### 12.8 หลังบ้านผู้ขาย `/seller`

**ภาพรวม** — 4 ตัวเลขที่ทำงานต่อได้ทันที (ออเดอร์ใหม่ / ต้องจัดส่งวันนี้ / แชทยังไม่ตอบ /
เงินพร้อมถอน) แต่ละช่องคือลิงก์ ไม่ใช่ตัวเลขประดับ ตามด้วย
รายการงานที่ต้องทำวันนี้ (เรียงตามเดดไลน์) และกราฟยอดขาย 14 วัน

**จัดการโพสต์** `/seller/listings`
- ตารางที่มี: รูปย่อ, ชื่อ, ราคา, สต็อก, ยอดดู, ยอดบันทึก, สถานะ, ดันล่าสุด
- เลือกหลายรายการเพื่อ: ปรับราคาพร้อมกัน, เปลี่ยนสถานะ, ลบ, ดัน
- ตัวกรองด่วน: ทั้งหมด / เผยแพร่ / ร่าง / หมดสต็อก / ใกล้หมดอายุ / ถูกระงับ
- แก้ราคาและสต็อกในบรรทัดได้เลย (inline edit) โดยไม่ต้องเปิดหน้าใหม่

**จัดการออเดอร์** `/seller/orders`
- แท็บตามสถานะพร้อมตัวเลข, การ์ดออเดอร์แสดงเดดไลน์แบบนับถอยหลังเมื่อเหลือ < 6 ชม.
- ปุ่มหลักเปลี่ยนตามสถานะ: รับออเดอร์ → กรอกเลขพัสดุ → พิมพ์ใบปะหน้า
- พิมพ์ใบปะหน้าหลายใบพร้อมกันเป็น PDF A4 (4 ใบ/แผ่น) หรือ 100x150mm สำหรับเครื่องพิมพ์ฉลาก

**กระเป๋าเงิน** `/seller/wallet`
- ยอดพร้อมถอน / ยอดรอปล่อย (พร้อมวันที่จะปล่อย) / ยอดกันไว้
- รายการเดินบัญชีมีตัวกรองและส่งออก CSV
- ถอนเงิน: เลือกยอด → ยืนยันด้วย OTP → แสดงกำหนดเวลาเข้าบัญชี

### 12.9 หลังบ้านผู้ดูแล `/admin`

**คิวตรวจสอบ** `/admin/queue` — สามคอลัมน์

```
┌──────────────┬────────────────────────────┬──────────────┐
│ รายการรอ (42) │  รายละเอียดที่เลือก             │ การกระทำ      │
│ ▸ โพสต์ #1231  │  รูปทั้งหมด + ข้อความเต็ม       │ [อนุมัติ  A]  │
│   ของปลอม     │  ประวัติผู้ขาย: 12 โพสต์        │ [ปฏิเสธ  X]  │
│ ▸ ร้าน #88    │  เคยถูกรายงาน 1 ครั้ง          │ [ระงับ    S]  │
│ ▸ รีวิว #442  │  คำที่ระบบตั้งข้อสังเกต: …       │ เหตุผล:       │
│              │  รายการใกล้เคียงในระบบ         │ [▾ เลือก]     │
└──────────────┴────────────────────────────┴──────────────┘
```

- คีย์ลัด: `J`/`K` เลื่อน, `A` อนุมัติ, `X` ปฏิเสธ, `S` ระงับ, `E` ยกระดับ, `?` ดูคีย์ลัด
- ทุกการกระทำต้องเลือกเหตุผลจากรายการก่อน ยืนยันด้วย Enter
- มี undo 10 วินาทีสำหรับทุกการกระทำ
- นับเวลาเฉลี่ยต่อรายการและแสดงให้แอดมินเห็น

**ข้อพิพาท** `/admin/disputes` — แสดงไทม์ไลน์ทั้งสองฝ่ายเรียงเวลาเดียวกัน
มีหลักฐานรูป ประวัติแชทที่เกี่ยวข้อง และปุ่มตัดสินที่ระบุยอดคืนได้ทันที

**สรุปตัวเลข** `/admin/metrics` — GMV, ออเดอร์, ผู้ใช้ใหม่, อัตราพิพาท, เวลาตอบเฉลี่ยของแอดมิน
เลือกช่วงเวลาได้ เทียบกับช่วงก่อนหน้า ส่งออก CSV

### 12.10 หน้าระบบ

| หน้า | ข้อกำหนด |
|---|---|
| 404 | ภาพประกอบป้ายร้านที่ว่าง + ช่องค้นหา + ลิงก์หมวดยอดนิยม 6 หมวด |
